按 [p5.md 的明确运行时命令](p5.md) 启动后端及客户端；P5后业务功能冻结，仅处理实际验收问题。保留已有账户/证书；健康检查应返回 stage=P3。使用可信本机 CA，不关闭证书校验。准备 Alice/Bob 两个已有账户、两个窗口；源文件和下载位置使用自己创建的测试目录，不改真实服务器数据库或上传对象来模拟异常。P4 界面身份代次修复的人工结果对应 F02，两个传输方向均获用户确认。

如需生成无敏感内容的边界文件，可在选定的**新空目录**里运行（示例目录若已存在请另取名）：

```powershell
$testDirectory = Join-Path $env:TEMP ('SFT-GUI-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $testDirectory | Out-Null
$generator = [Security.Cryptography.RandomNumberGenerator]::Create()
try {
  foreach ($size in 0,1,8191,8192,8193,48017) {
    $bytes = New-Object byte[] $size
    $generator.GetBytes($bytes)
    [IO.File]::WriteAllBytes((Join-Path $testDirectory ("中文-$size.bin")), $bytes)
  }
} finally { $generator.Dispose() }
$testDirectory
```

也可直接使用自己已有的小测试文件。为方便点击取消，可另选一个小于 100 MiB 的多块文件；本机传输很快，结束后点击取消不能撤销已完成结果。

三份文件只读比较示例（把三个路径替换为本次文件）：

```powershell
$checkPaths = @('源文件的完整路径', 'D:\UCAS\软件与系统安全\lab1\server-node\data\uploads\objects\返回的fileId.bin', '下载文件的完整路径')
foreach ($path in $checkPaths) {
  Get-Item -LiteralPath $path | Select-Object FullName,Length
  Get-FileHash -LiteralPath $path -Algorithm SHA256
}
```

若采用自定义 SFT_DATA_DIR，服务器对象路径也随数据目录变化；客户端不会收到该真实路径。普通操作不要修改 objects 文件或 SQLite。
