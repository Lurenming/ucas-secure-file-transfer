# 安全文件传输软件
本仓库是本人完成的中国科学院大学课程《软件与系统安全》的大作业1B：安全文件传输软件的代码仓库。前端图形界面用Visual Studio编写C#代码实现，而后端基于node.js开发。
### 使用指南
+ 第一次使用本项目时，双击“首次配置.cmd”，完成初步配置。
+ 双击“账户管理.cmd”，顺着提示输入账号名和密码，注册一个账户。也可以在这里调节本账户是普通用户还是vip用户。
+ 双击“启动服务器.cmd”，启动软件的后端服务器，可以选择账户是密码登录还是证书登录。
+ 双击“启动客户端.cmd”，启动一个软件的客户端，在客户端内输入账号和密码，或者提供自己的客户端证书和私钥就能正常使用了。
